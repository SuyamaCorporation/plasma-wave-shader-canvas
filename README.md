# Plasma Wave CSS/Canvas Shader Effect
Full-page animated plasma wave effect computed per-pixel using sinusoidal interference patterns.
## Features
- Per-pixel color computed using four overlapping sine waves including a radial term
- Sliders for x-frequency, y-frequency, animation speed, and color saturation
- Four palette presets: Rainbow, Fire, Ice, Neon
- FPS display
- Renders at half resolution and scales up 2x for performance
## Tech
Static SPA · Tailwind CDN · Canvas/localStorage
